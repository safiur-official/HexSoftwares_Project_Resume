
# 🌐 Personal Resume Website (HTML Only)

A structured and professional single-page resume website built using **pure HTML5 only**.

This project demonstrates strong understanding of core web fundamentals without using CSS, JavaScript, frameworks, or external libraries.

---

## 🚀 Features

- 📄 Single-page scroll resume layout  
- 🧭 Navigation bar using anchor links  
- 🖼️ Profile photo section  
- 🔗 Hyperlinked contact details (Email, Phone, LinkedIn, GitHub, Location)  
- 📜 Hyperlinked internship & certification documents  
- 📑 Structured sections (About, Education, Projects, Internship, Skills, Contact)

---

## 🛠️ Tech Stack

- HTML5 (Semantic Tags)
  
> No CSS  
> No JavaScript  
> No frameworks
